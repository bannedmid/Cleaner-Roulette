### Project Description
Deletes a random file from your system.

### The Problem (that doesn't exist)
Cleaning up space on a device

### The Solution (that nobody asked for)
Deletes a random file from the system but it is totally random. It can include any important files so could be used to create space quickly without going through the trouble of thinking what should be deleted.
